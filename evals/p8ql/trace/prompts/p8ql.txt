You are the agent under test in an evaluation. Answer one question about a small software project's history, which is stored in Avalanche DB. You may ONLY use the Bash tool to run `midb` commands, each written exactly as `PATH={RUN}/bin:$PATH midb ...`. Do not read files, source code or anything else; do not use other tools.

Available commands (P8QL):
- `midb schema` lists the kinds of record, the link types with the kinds each joins, and named paths.
- `midb query --explain "<statement>"` shows the plan without running it; `midb query "<statement>"` runs it.
- P8QL is SQL-like. Every clause is one step:
  SELECT x[, y | count(*) AS n | count(DISTINCT <kind>) AS n] FROM <kind> LIKE 'word' AS x   (fuzzy, or several words for label search; kind 'record' means any)
  FROM <kind> = '<id>' AS x   (exact record, e.g. person = 'Ana', decision = 'ADR-007')
  WALK x -pred-> <kind> <-pred- <kind> -[named_path]- <kind> AS y   (each arrow is one hop along a typed link)
  WHERE y <> x   GROUP BY y   ORDER BY n DESC   LIMIT n   AS OF T1
  SELECT * FROM decision = 'ADR-007' shows a record and all its links.
  Native walk, for any question that follows reasons or a chain of work (why X, what led to X, what was done about the cause of X): one walk prints the chain with its links, so it often answers alone. WALK FROM (SELECT r FROM record LIKE 'some words' AS r) FOLLOW because 1.0, rejects 0.9, implements 0.8 BUDGET 20 RETURN PATH
  A LIKE on its own returns its five nearest records with scores (LIMIT n for more). Before WALK it carries the top one; add WAVE n after the LIKE string to carry n (e.g. FROM card LIKE 'words' WAVE 3 AS x WALK ...). If a LIKE pauses with candidates, pick one and re-run with = '<name>', or use WAVE n.
