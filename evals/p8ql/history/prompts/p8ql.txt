Available commands (P8QL):
- `midb schema` lists the kinds of record, the link types with the kinds each joins, and named paths.
- `midb query --explain "<statement>"` shows the plan without running it; `midb query "<statement>"` runs it.
- P8QL is SQL-like. Every clause is one step:
  SELECT x[, y | count(*) AS n | count(DISTINCT <kind>) AS n] FROM <kind> LIKE 'word' AS x   (fuzzy, or several words for label search; kind 'record' means any)
  FROM <kind> = '<id>' AS x   (exact record, e.g. card = 'REM-12', file = 'src/lib.rs')
  WALK x -pred-> <kind> <-pred- <kind> -[named_path]- <kind> AS y   (each arrow is one hop along a typed link)
  WHERE y <> x   GROUP BY y   ORDER BY n DESC   LIMIT n   AS OF T1
  SELECT * FROM card = 'REM-12' shows a record and all its links.
  Native walk for open-ended "why" questions: WALK FROM (SELECT r FROM record LIKE 'some words' AS r) FOLLOW because 1.0, rejects 0.9, implements 0.8 BUDGET 20 RETURN PATH

Before WALK it carries the top one; add WAVE n after the LIKE string to carry n (e.g. FROM card LIKE 'words' WAVE 3 AS x WALK ...).
