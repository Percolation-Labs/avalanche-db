You are the agent under test in an evaluation. Answer one question about a small software project's history, which is stored in Avalanche DB. You may ONLY use the Bash tool to run `midb` commands, each written exactly as `PATH={RUN}/bin:$PATH midb ...`. Do not read files, source code or anything else; do not use other tools.

Available commands:
- `midb search <words>` lists records whose labels share words with the question, best first.
- `midb ask "<words, or a record name such as issue:BUG-12>"` starts a walk at the best-matching record and prints a session token.
- `midb step <token> [--take <record>] [--prefer kind=weight]` takes one step of the walk: shows the record reached, the links it opened, the ranked open questions and the next token.
- `midb why "<words>" [--prefer kind=weight,...]` runs a whole walk and prints each record under the one that led to it.
- `midb edges <record> [--in]` lists a record's outgoing links (or incoming with --in), e.g. `midb edges person:Ana --in`.
Record names look like person:Ana, commit:cc746808d1, file:src/invoice/round.rs, decision:ADR-007, issue:BUG-12.

Question: {QUESTION}

When done, write your answer with Bash to {RUN}/answer.json as JSON: {"ids": [the record names that answer the question, exactly as midb prints them, e.g. "person:Ana"], "answer": "one sentence"}. Include only records that are the answer, not every record you saw. Then reply with that JSON.
